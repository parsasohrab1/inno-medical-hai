# کارت داده — inno-medical-hai

- **منبع:** کاملاً مصنوعی؛ تولید با `python -m inno_medical_hai generate --seed N` (قطعی). هیچ داده‌ی بیمار، شخص یا مرکز واقعی در ریپو نیست.
- **نمونه‌ی ذخیره‌شده:** `data/sample/*.csv` (seed=0).
- **فرض‌ها:** ۶ بخش × ۴ ارگانیسم × ۳۶۵ روز؛ نرخ پایه‌ی ثابت؛ ۵ خوشه‌ی تزریق‌شده با شدت ۵ تا ۸ برابر؛ ایزوله‌های تکراری بیمار و تعریف رسمی عفونت بیمارستانی مدل نشده است.
- **استفاده‌ی مجاز:** توسعه و آزمون نرم‌افزار. استفاده برای آموزش/ارزیابی مدل بالینی یا هر تصمیم واقعی مجاز نیست.
- **حریم خصوصی:** هنگام ورود داده‌ی واقعی باید بی‌نام‌سازی، مجوز اخلاق و توافق‌نامه‌ی اشتراک داده انجام شود.
