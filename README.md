# inno-medical-hai

**پایش عفونت بیمارستانی**

> وضعیت: **TRL 4** — نمونه‌ی آزمایشگاهی با اعتبارسنجی اجزا روی **داده‌ی مصنوعی** (بدون داده‌ی بیمار). برای ارزیابی بالینی یا میدانی آماده نیست. ← [مستندات TRL](docs/TRL.md)

## نیاز شناسایی‌شده
عفونت‌های بیمارستانی و مقاومت آنتی‌بیوتیکی بدون پایش زودهنگام.

## محصول
هشدار زودهنگام خوشه‌های عفونت و پایش الگوی مقاومت.

## کاربران و ذی‌نفعان
کمیته‌ی کنترل عفونت، آزمایشگاه

## قابلیت‌های هدف
- تشخیص خوشه در زمان و مکان
- نقشه‌ی مقاومت آنتی‌بیوتیکی
- گزارش دوره‌ای به کمیته

## داده
نتایج کشت، بخش، تاریخ، آنتی‌بیوگرام. در مراحل اولیه فقط داده‌ی مصنوعی یا بی‌نام‌شده استفاده می‌شود.

## ریسک‌ها و محدودیت‌ها
هشدار کاذب؛ حساسیت داده‌ی بیماران.

## مسیر پیشنهادی
1. ✅ TRL 1 → 2: تعریف نیاز و معیار موفقیت (جدول معیارها در [docs/TRL.md](docs/TRL.md)).
2. ✅ TRL 3: نمونه‌ی آزمایشگاهی روی داده‌ی مصنوعی همراه با تست.
3. ✅ TRL 4: اعتبارسنجی اجزا در آزمایشگاه با تست‌های خودکار (CI روی هر push).
4. ⬜ TRL 5: اعتبارسنجی در محیط مرتبط با داده‌ی واقعی بی‌نام‌شده — نیازمندی‌ها در [docs/TRL.md](docs/TRL.md).

## یادداشت
این ریپو بخشی از مجموعه‌ی `inno-medical-*` برای دانشگاه‌های علوم پزشکی و وزارت بهداشت است. هیچ‌یک از خروجی‌ها جایگزین قضاوت بالینی نیست.

## راه‌اندازی سریع
```bash
pip install -r requirements.txt           # فقط numpy
export PYTHONPATH=src
python -m inno_medical_hai generate --out data/sample # تولید داده‌ی مصنوعی (قطعی با seed)
python -m inno_medical_hai validate                   # اجرای معیارهای TRL 4 روی ۳ seed
python -m inno_medical_hai demo
python -m unittest discover -s tests -v
```

## آنچه پیاده‌سازی شده
اسکن پنجره‌ای پواسون (۵، ۷ و ۱۴ روز) برای هر بخش×ارگانیسم، ادغام هشدارها، آنتی‌بیوگرام با بازه‌ی اطمینان ویلسون، گزارش کمیته.
